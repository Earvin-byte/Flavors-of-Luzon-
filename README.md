# Flavors of Luzon

Static front-end website (HTML5, CSS3, vanilla JavaScript). No build step.

## Deploy on GitHub Pages
1. Create a GitHub repository and upload the contents of this folder (index.html at the root).
2. Settings > Pages > Deploy from a branch > main > / (root).
3. Open the live URL, then test every page, the gallery, search and the menu on desktop and phone.
4. Put the live URL in your final submission.

## Contact form
The contact form sends messages to webdevemailcs@gmail.com through FormSubmit (see FORM_ENDPOINT in js/app.js). After deploying, send one test message from the live site and click the activation link FormSubmit emails to that address.
